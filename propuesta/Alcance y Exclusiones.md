# Alcance y Exclusiones

## Dentro del alcance

- Analizar la logica actual de alertas de IntegraVida.
- Diseñar una capa CDSS basada en Drools.
- Implementar reglas clinicas iniciales de farmacovigilancia.
- Registrar auditoria de reglas activadas.
- Exponer la trazabilidad de alertas mediante backend y, si corresponde, frontend.
- Construir pruebas de regresion para reglas clinicas.
- Comparar mantenibilidad entre logica condicional y motor de reglas.
- Validar la utilidad de las alertas con juicio de experto.

## Fuera del alcance principal

- Reconstruir IntegraVida desde cero.
- Cambiar toda la arquitectura del sistema.
- Implementar OCR de glucometros como aporte principal.
- Implementar IoT/BLE/MQTT como aporte principal.
- Entrenar un modelo LSTM predictivo.
- Crear un motor de reglas propio desde cero.
- Sustituir el criterio medico profesional.

## Trabajo futuro

- OCR para lectura automatica de glucometros.
- Integracion con dispositivos IoT o wearables.
- Modelos predictivos de glucosa.
- Edicion dinamica de reglas por personal clinico.
- Outbox pattern para eventos clinicos a mayor escala.
