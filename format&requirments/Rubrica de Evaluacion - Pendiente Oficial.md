# Rubrica de Evaluacion - Pendiente Oficial

> La rubrica oficial de tesis/Trabajo de Investigacion UPC no fue encontrada como fuente publica confiable. Esta nota separa lo confirmado de lo que debe solicitarse al curso, asesor o aula virtual.

## Estado

- No usar rubricas de Scribd, Studocu, Facebook o documentos no oficiales como fuente normativa.
- Solicitar al docente/asesor la rubrica vigente del curso correspondiente.
- Guardar aqui la rubrica oficial cuando se obtenga.

## Criterios esperados por inferencia academica

Estos criterios son una matriz de preparacion, no una rubrica oficial:

| Criterio | Que preparar para IntegraVida |
|---|---|
| Problema y justificacion | Problema claro: reglas clinicas hardcodeadas no escalan |
| Estado del arte | Antecedentes UPC + literatura internacional sobre CDSS/Drools |
| Aporte de ingenieria | Mejora evolutiva sobre sistema real desplegado |
| Diseño de solucion | Arquitectura CDSS integrada a DDD/CQRS |
| Implementacion | Reglas Drools, auditoria, endpoint, pruebas |
| Evaluacion | Experimento mantenibilidad: if/else vs Drools |
| Validacion | Juicio de experto clinico y/o validacion tecnica |
| Comunicacion | Documento ordenado, citas APA, diagramas, defensa clara |
| ABET | Evidencia trazable para SO1-SO7 |

## Evidencias que conviene producir desde ahora

- Capturas del sistema desplegado.
- Diagramas del estado actual y propuesto.
- Tabla de reglas clinicas candidatas.
- Bitacora de decisiones.
- Matriz de antecedentes.
- Resultados de pruebas.
- Matriz ABET.

## Preguntas para el asesor

- La modalidad final sera tesis, Trabajo de Investigacion, TSP o Capstone?
- Se usara informe largo, formato articulo o ambos?
- Cuales son los pesos de la rubrica?
- Se requiere validacion con usuario, experto, ambos o experimento tecnico?
- Que Student Outcomes ABET deben evidenciarse obligatoriamente?
- Que plantilla y formato de citacion se exigira?
