# Checklist de Entregables UPC

> Lista viva para controlar documentos, evidencias y anexos de la tesis.

## Documentos principales

- [ ] Plantilla oficial de tesis.
- [ ] Rubrica oficial del curso/tesis.
- [ ] Caratula.
- [ ] Resumen.
- [ ] Abstract.
- [ ] Indice general.
- [ ] Indice de tablas.
- [ ] Indice de figuras.
- [ ] Capitulos completos.
- [ ] Referencias en APA 7.
- [ ] Anexos.
- [ ] Declaracion de modalidad: tesis, trabajo de investigacion, TSP o Capstone.

## Evidencias tecnicas

- [ ] Repositorio backend.
- [ ] Repositorio frontend.
- [ ] Evidencia de despliegue.
- [ ] Diagramas de arquitectura.
- [ ] Pruebas automatizadas.
- [ ] Resultados de evaluacion de mantenibilidad.
- [ ] Evidencia de reglas Drools.
- [ ] Evidencia de auditoria de reglas.
- [ ] Baseline de reglas condicionales.
- [ ] Suite de regresion de reglas clinicas.
- [ ] Tabla de comparacion if/else vs Drools.

## Evidencias academicas

- [ ] Matriz de consistencia.
- [ ] Objetivos e indicadores.
- [ ] Pregunta de investigacion.
- [ ] Hipotesis.
- [ ] Estado del arte UPC.
- [ ] Marco teorico CDSS/Drools/Rete.
- [ ] Matriz de fuentes bibliograficas.
- [ ] Instrumento de validacion de experto.
- [ ] Resultados de encuesta.
- [ ] Mapeo ABET.
- [ ] Cronograma.
- [ ] EDT o plan de proyecto si aplica.
- [ ] Ruta de evolucion 5to-10mo ciclo.

## Pendientes de confirmacion con asesor

- [ ] Formato final del documento.
- [ ] Pesos de la rubrica.
- [ ] Criterios ABET exigidos.
- [ ] Si se permite presentar el sistema base como caso de estudio ya desplegado.
- [ ] Si la evaluacion debe priorizar experimento tecnico, validacion clinica o ambos.
